# Client

The React + Vite front end. See the [main README](../README.md) for setup and an overview.

- `npm run dev`: dev server on http://localhost:5173 (proxies `/api` and `/auth` to the API on port 3000)
- `npm run build`: type-check and build to `dist/`
- `npm run lint`: oxlint

UI rules live in [docs/ui-design-rules.md](../docs/ui-design-rules.md).
